Privacy Policy

Last Updated: June 14, 2026

Company: Blackthorne Groupe LLC

Blank Network Proxy is designed to operate locally on your device. The application does not collect, transmit, sell, or share personal information with Blackthorne Groupe LLC or any third parties.

1. Overview

Blank Network Proxy is a network analysis and proxy utility that allows users to inspect and monitor network traffic generated by devices under their control. All traffic processing and analysis are performed locally on the user's device.

2. No Data Collection

Blackthorne Groupe LLC does not collect, store, receive, or transmit user data through Blank Network Proxy.

  • No names, email addresses, or account information are collected
  • No IP addresses or device identifiers are transmitted to us
  • No analytics, telemetry, or tracking services are used
  • No advertising SDKs are included
  • No background usage data is collected

3. Local Processing

Blank Network Proxy performs all network inspection and proxy functionality locally on the user's device.

  • Network traffic is analyzed locally
  • Captured traffic is not transmitted to Blackthorne Groupe LLC
  • No remote servers are used to process network data
  • No cloud-based inspection or monitoring occurs

Depending on the features enabled by the user, the application may display information such as domains, IP addresses, DNS requests, connection metadata, HTTP requests, HTTPS requests, or network activity generated by devices connected through the proxy. This information is processed locally and is not transmitted to the Company.

4. HTTPS Traffic Inspection

Blank Network Proxy includes optional HTTPS inspection functionality.

  • HTTPS inspection is disabled unless explicitly enabled by the user
  • Users must manually install and trust a local certificate before HTTPS inspection can occur
  • HTTPS traffic inspection occurs entirely on-device
  • Decrypted traffic is not transmitted to Blackthorne Groupe LLC

Users are responsible for complying with all applicable laws, regulations, and policies when inspecting network traffic.

5. Data Storage

The application does not automatically transmit or back up captured traffic.

  • Traffic information is displayed locally during application use
  • Session data may be stored locally on the device when explicitly saved by the user
  • Stored sessions remain under the user's control
  • Blackthorne Groupe LLC does not have access to locally stored sessions

6. Data Sharing

Blank Network Proxy does not share user data with third parties.

  • No analytics providers
  • No advertising networks
  • No data brokers
  • No third-party monitoring services

7. Exported Data

The application may allow users to export captured network information.

  • Exporting is initiated solely by the user
  • Exported files remain under the user's control
  • The application does not automatically transmit exported data
  • Users are responsible for how exported data is stored or shared

8. Security

Because Blank Network Proxy does not transmit captured traffic to Blackthorne Groupe LLC, network information remains on the user's device unless the user explicitly exports or shares it.

Users should protect their devices and exported session files appropriately, particularly when network inspection features are enabled.

9. Children's Privacy

Blank Network Proxy does not knowingly collect personal information from anyone, including children under the age of 13.

10. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected by updating the "Last Updated" date on this page.
